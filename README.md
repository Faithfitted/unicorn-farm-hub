# Unicorn Farm Hub

A mobile-friendly farm record-keeping app with offline support.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to finish deployment. The published address will appear in Pages settings.

## Important data note
Farm records are saved in the browser on the device where they are entered. GitHub Pages is static hosting; it does **not** provide cloud database storage or automatic syncing between devices. Use **Backup & data → Download full backup** regularly. To move existing records, export a JSON backup from the old app and restore it in the hosted app. Keep the original backup and old app data until you confirm the restore worked.

A first successful visit while online is required before offline use.
